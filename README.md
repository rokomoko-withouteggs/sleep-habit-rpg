# 睡眠習慣RPG - Dream Guardian

睡眠習慣をゲーム進行・育成・報酬に連動させたソロRPG + 週末チームボス（擬似オンライン）ゲームです。

## 🎮 ゲーム概要

- **睡眠記録**: 毎日の睡眠を記録し、スコアに応じて報酬を獲得
- **ストーリーモード**: 夢の世界を舞台にしたバトルRPG
- **週末ボス**: 土曜・日曜限定のチーム協力バトル（擬似オンライン）
- **ガチャ**: キャラクターや装備を獲得
- **育成**: キャラクターのレベルアップと編成

## 🚀 セットアップ

### 必要環境
- Node.js 18.x 以上
- npm 9.x 以上

### インストール

```bash
# 依存パッケージのインストール
npm install

# 開発サーバー起動
npm run dev

# ブラウザで http://localhost:3000 を開く
